# Citation Linker for Word

Word VBA macro for linking numbered citations to bookmarks.

## Files

- `CitationNavigator.bas` — main macro
- `frmBookmarkPick.frm` — userform definition
- `frmBookmarkPick.frx` — userform resources
- `CitationLinker.dotm` — ready-to-use template

## Installation

Import `.bas`, `.frm`, and `.frx` into VBA Editor, or load the `.dotm`.
